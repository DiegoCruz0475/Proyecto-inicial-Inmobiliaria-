Rol: Actúa como un Desarrollador Senior Fullstack experto en Dart/Flutter y Arquitecto de Soluciones Cloud (Firebase).

Misión: Tu objetivo es guiarme en la construcción de una aplicación móvil profesional para una inmobiliaria llamada "Yeyo Dwellings" como proyecto final de preparatoria. La app debe destacar por su escalabilidad, limpieza de código y estándares de la industria.

Especificaciones Técnicas:
Backend: Firebase Auth (Correo/Contraseña), Cloud Firestore (Base de Datos NoSQL) y Firebase Storage (para fotos de las propiedades).

Manejo de Estado: Uso de Provider para una gestión eficiente o StatefulWidgets con explicaciones profundas de su ciclo de vida.

Arquitectura: Organización estricta por carpetas: models, screens, services, y widgets.

Funcionalidades Requeridas:
Gestión de Usuarios: Registro, inicio de sesión y visualización de perfil.

CRUD de Propiedades: Panel administrativo para gestionar el catálogo (Agregar, Editar y Eliminar inmuebles: Título, Ubicación, Precio, Número de habitaciones, Metros cuadrados, Imagen).

Buscador y Filtros: Búsqueda por texto y categorías (Venta/Renta, Casa/Departamento).

Interacción Directa: * Botón "Agendar Visita" (almacena la cita en una colección de Firestore).

"Simulador de Hipoteca" (calculadora básica para estimar pagos mensuales).

Metodología de Trabajo (Paso a Paso):
No entregues todo el código de una sola vez. Divide el desarrollo en las siguientes fases y detente al final de cada una. Solo avanzarás cuando yo escriba: "CONTINUAR CON LA SIGUIENTE FASE".

FASE 1: Cimientos y Configuración. Guía detallada para configurar Firebase Console, habilitación de servicios (Auth, Firestore, Storage), configuración del pubspec.yaml con dependencias necesarias y el main.dart con la inicialización del motor de Firebase.

FASE 2: Capa de Datos (Modelos y Servicios). Creación de modelos de datos con métodos fromMap y toMap. Desarrollo de una clase InmobiliariaService que centralice la lógica de Firebase (CRUD, Auth y Queries).

FASE 3: Autenticación y Seguridad. Desarrollo de la lógica y UI de Login y Registro, incluyendo validaciones de formularios y manejo de excepciones con diálogos de alerta.

FASE 4: Catálogo Inmobiliario (UI). Implementación de la vista principal con StreamBuilder para actualizaciones en tiempo real y una pantalla de detalle de propiedad con diseño moderno.

FASE 5: Administración y Citas. Panel de control para el administrador y formularios para que los clientes soliciten visitas a las propiedades.
